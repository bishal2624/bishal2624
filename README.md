## About Me

I'm pursuing a B.Tech in Computer Engineering at Pimpri Chinchwad University (PCU) and a BS in Applied AI and Data Science at IIT Jodhpur.

My interests span **software engineering, artificial intelligence, machine learning, and full-stack development**. I enjoy turning concepts into practical projects and learning through hands-on implementation.

I'm currently strengthening my skills in backend engineering, REST API development, relational databases, responsive frontend development, and applied AI. My goal is to build reliable, useful software while contributing to the developer community.
